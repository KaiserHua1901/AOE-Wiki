## Installing a local server

1. Download and unzip the server zip file from CurseForge.
2. Run the `startserver.bat` script. (or `.sh`, on linux or macOS)
3. Respond with `TRUE` to the EULA question.

Now you should have a running local server.

!!! Note
	Be sure you have the [right Java version](../performance.md#which-java-to-use) for the modpack you want to play

## Installing a hosted server

The choices here depend on the hosting service you have chosen.

Generally, they may offer pre-packaged installs for modpacks—including AOE's—or you may upload a working server install.

For the later, upload the whole server created with the local server install process described above. Consult your hosting service for how exactly to setup starting your uploaded server; the details depend on their service.
