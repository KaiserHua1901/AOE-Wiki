# Sharing with Friends

*<h3>Looking for a method to play with friends without needing to pay?</h3>*

## Easy Methods

These methods don't involve setting up a separate local server.

### **e4mc**

**e4mc** [(CurseForge)](https://www.curseforge.com/minecraft/mc-mods/e4mc) [(Modrinth)](https://modrinth.com/mod/e4mc) enables sharing your local "Open to LAN" game to the internet. It only needs to be installed on the side that becomes the host. It's simple and performant.

!!! tip
    As of version 5.4.1 and above, *e4mc* includes `/whitelist` and `/ban` commands, making it safer to use than before.

### Essential Mod

## Other Options

### playit.gg

[playit.gg](https://www.playit.gg) is a global proxy, tunneling service. It requires you run it's program on your computer, has paid options, but also offers a free base tier.

!!! warning
    ***Do*** use a local, online mode, server setup with this so you can use the server's whitelist functionality.
    *playit.gg* uses a fixed, non-negligible amount of IPs, and only shuffle ports for each IP address. This makes finding the IP easier than for other methods of finding IPs.

### Hamachi

[Hamachi](https://vpn.net/) is a paid, hosted VPN service.
